REST Operations

GET All Bookings
/bookings

Returns the complete list of bookings. Demonstrates REQ 2 (GET) and REQ 9 (JSON response).

GET Booking By ID
/bookings/:id

Fetches one booking by route parameter. Demonstrates REQ 3 (route params) and REQ 10 (200 OK).

POST Create Booking
/bookings

Sends a JSON body to create a new booking. Demonstrates REQ 5 (req.body) and REQ 10 (201 Created).

PUT Update Booking
/bookings/:id

Merges the body into an existing booking. Demonstrates REQ 3 (route params) and REQ 10 (200 OK).

DELETE Delete Booking
/bookings/:id

Removes a booking permanently. Demonstrates REQ 2 (DELETE route) and REQ 10 (200 with message).

GET Invalid Booking
/bookings/INVALID-ID

Intentionally requests a non-existent ID. Demonstrates REQ 10 (404 Not Found) and the error response shape.

500 — Centralized Error Handler

                        
GET /debug/error → next(err) → errorHandler

                    

                    500
                

                

                    

                        The route intentionally calls throw new Error() then passes it to
                        next(err). Express skips all normal middleware and invokes the
                        four-parameter errorHandler(err, req, res, next) registered
                        last in app.js.
                    

                    
                    

                        

                            GET
                            /debug/error
                            HTTP {{errDemo.error.status}}
                        

                        

                        
Sending…

                    

                    

                        errorHandler in middleware/errorHandler.js received
                        the thrown error and responded with
                        res.status(500).json({ error: "Something went wrong" }).
                        The message field provides a dev-friendly description without
                        exposing sensitive internals.

404 — Not Found

                        
GET /debug/bookings/999999

                    

                    404
                

                

                    

                        Express looks up req.params.id in the bookings array.
                        When no match is found the route calls
                        res.status(404).json({ error: "Booking not found" }).
                        This is a handled 404 — the errorHandler is not involved.
                    

                    

                        
                        
                    

                    

                        

                            GET
                            {{errDemo.notFound.url}}
                            HTTP {{errDemo.notFound.status}}
                        

                        

                        
Sending…

                    

                    

                        The route handler executed if (!booking) and explicitly returned 404.
                        This is a controlled error — not a crash.
                        The server continues running normally after this response.

400 — Bad Request

                        
POST /debug/bookings (missing fields)

                    

                    400
                

                

                    

                        The route validates req.body parsed by express.json().
                        When required fields are absent it returns 400 Bad Request
                        immediately — the server never touches the database.
                        Supply a valid JSON body to see 201 Created instead.
                    

                    

                        
                        
                    

                    
                    

                        

                            POST
                            /debug/bookings
                            HTTP {{errDemo.badRequest.status}}
                        

                        

                        
Sending…

                    

                    

                        All required fields were present — server returned 201 Created.
                        Clear the textarea and click again to see the 400 response.
                    

                    

                        The server found missing fields in req.body and returned
                        400 Bad Request without creating any resource.
                        The client is responsible for fixing the payload and retrying.
