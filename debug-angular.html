AngularJS Debugging Demonstration

Dashboard Angular Debug
ℹ️ Laboratory demonstration page. Open Chrome DevTools → Console (F12) before starting. All six demonstrations run entirely in this browser — no backend required. No production page is affected.
1

Two-Way Data Binding

ng-model="debugInput" links the <input> to $scope.debugInput. Typing in the field updates the scope instantly, and the {{debugInput}} expression below re-renders.

Template expression {​{debugInput}}
{{debugInput || '(empty — start typing)'}}
$scope.user object
$scope.user = {
  name: "{{user.name || ''}}" ,
  email: "{{user.email || ''}}"
}
2

Controller Binding

ng-controller="DebugController" on <body> registers this controller. The Console confirms initialization on page load.

Property Source Live Value
ng-controller attribute HTML <body> DebugController ✅

$scope.user.name debug-controller.js {{user.name || '(empty)'}}
$scope.user.email debug-controller.js {{user.email || '(empty)'}}
💡 Open the Console and type the command shown in Demonstration 3 below to inspect this controller's live scope object.
3

Scope Inspection

Use Chrome DevTools to inspect the live AngularJS scope object

Steps

1. // Press F12 to open Chrome DevTools, then click the Console tab
2. // Get the DebugController scope:
var s = angular.element(document.querySelector( '[ng-controller="DebugController"]' )).scope();
3. // Inspect scope variables:
s.debugInput      // → whatever you typed in Demo 1
s.user           // → { name: "...", email: "..." }
s.user.name      // → current value of user.name
4. // Type in Demo 1 input, then re-run s.debugInput to see the new value
5. // Trigger $apply to push a change from the Console to the UI:
s.$apply(function () { s.debugInput = 'Hello from DevTools'; });
4

$watch()

$scope.$watch('debugInput', …) fires on every digest cycle where debugInput changes. Each change is logged to the Console and shown in the watch log below.

// From debug-controller.js
$scope.$watch('debugInput', function (newValue, oldValue) {
  console.log('debugInput changed:', oldValue, '→', newValue);
});

Type in the Demo 1 input — each keystroke adds a row below:

Current value: {{debugInput || '(empty)'}}
// Open Console (F12) and type — you will see:
// debugInput changed: "" → "h"
// debugInput changed: "h" → "he" …
5

Undefined Variable Debugging

AngularJS renders an undeclared scope variable as an empty string with no error — making it a silent, easy-to-miss bug.

✅ Declared variable
// debug-controller.js
$scope.definedValue = 'AngularJS Debugging';
Rendered: {​{definedValue}}
{{definedValue || '(not yet set — see Demo 1)'}}
❌ Undeclared variable — silent bug
// debug-controller.js — intentionally omitted:
// $scope.undefinedValue = …;
Rendered: {​{undefinedValue}}
{{undefinedValue}} (blank — not an error, but a silent bug)

Identifying the bug in DevTools Console

› var s = angular.element(document.querySelector( '[ng-controller="DebugController"]' )).scope();
› s.undefinedValue     // → undefined    ← confirms the variable is missing
› typeof s.undefinedValue   // → "undefined"
› s.debugInput        // → whatever you typed (confirming this IS declared)

Incorrect Binding Debugging

A typo in ng-model creates a new, unrelated scope property — the intended variable is never updated.

⚠️ Broken Binding Example
What the controller declares What the input actually binds to Result
$scope.user = { name: '' } ng-model="debugUser.name" user.name never updates ❌
Expected variable: user.name    Incorrect variable: debugUser.name
$scope.user.name
"{{user.name}}" (stays empty — bug!)
$scope.debugUser.name (auto-created)
"{{debugUser.name}}" (wrong target)
✅ {{fixMessage}}
✅ Corrected Binding
$scope.user.name (live)
"{{user.name || '(start typing above)'}}"

❌ Before (broken)

ng-model="debugUser.name"

✅ After (fixed)
